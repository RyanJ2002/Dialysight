# 系統架構圖（文字版）

> 正式簡報需要一張圖檔。這份是繪圖時的依據。
> 建議用 draw.io 或 Excalidraw 畫，匯出 PNG 放 `docs/architecture.png`。

## 需要畫出來的三件事

1. **什麼跑在 Hailo、什麼跑在 host CPU** — 這是評審最想看清楚的分界
2. **影像在哪裡停住** — 影像不出床邊，網路上只有文字
3. **雙通道** — 快通道與慢通道分岔的位置
